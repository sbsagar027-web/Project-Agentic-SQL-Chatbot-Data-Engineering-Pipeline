# Project-Agentic-SQL-Chatbot-Data-Engineering-Pipeline
This project implements a modern cloud data engineering pipeline that ingests data from multiple sources, processes it incrementally using Databricks and Apache Spark, performs data quality validation, and builds a One Big Table (OBT) for downstream analytics and AI-powered SQL querying.

The pipeline supports both CDC-based ingestion from an Agentic Database and file-based ingestion from Amazon S3. Apache Airflow is used for orchestration, while Databricks handles scalable data processing and transformation.
